# Cyber Notes

A polished, dependency-free cybersecurity study dashboard featuring:

- Topic navigation and search
- Responsive layout
- Persisted light/dark theme
- Exam-prep notes covering course overview, security goals, threats and risk,
  security engineering, attacks and adversaries, and Diffie-Hellman key exchange
- Interactive answer reveals, knowledge checks, and expandable definitions

Open `index.html` directly in a browser, or serve the directory locally with:

```sh
python3 -m http.server 8000
```

GitHub Pages deploys automatically after changes are merged into `main`.
